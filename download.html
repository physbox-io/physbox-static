PhysBox Native v1.0.0

The C++20 desktop build of Mesh — MuJoCo running natively, a GPU-accelerated viewport with 4x multisampled anti-aliasing, and every feature of the Mesh web app. Available for Linux and Windows.

PhysBox-Native-1.0.0-x86_64.AppImage
Download for Linux

x86-64 with AVX2 (Haswell, 2013 or newer). Needs a GL 3.3-capable driver and the usual X11 runtime libraries.

Detected on this machine
Windows
PhysBox-Native-1.0.0-x64-Setup.exe
Download for Windows

Windows 10 or 11, x64 with AVX2 (Haswell, 2013 or newer). TLS is handled by Schannel, so there is nothing else to install.

macOS is not currently supported. Prefer to build it yourself? The desktop source builds with CMake on both platforms.

After downloading

Linux — mark the AppImage executable and run it: 

chmod +x PhysBox-Native-1.0.0-x86_64.AppImage
./PhysBox-Native-1.0.0-x86_64.AppImage

Windows — run the installer and launch PhysBox Native from the Start menu. SmartScreen may warn on first run while the build's signature reputation is still new.

Sign in from the app's account menu to pick up your cloud saves. Copilot keys and the theme live in ~/.config/physbox-native/settings.json.
