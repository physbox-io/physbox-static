Sign in to set the Claude and Gemini API keys your copilot uses once, and have them waiting in Volt, Mesh and Etch on every browser you sign into.

Account Settings

What you save here is stored against your account, not this browser. Volt, Mesh and Etch read it when they open and again when you sign in, so a change made on this page is in all three the next time each one loads.

Copilot API keys

The AI copilot in each app calls the model provider directly from your browser with your own key. PhysBox holds the key so it can hand it to the apps; it never makes requests on your behalf.
